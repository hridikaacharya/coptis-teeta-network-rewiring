# Interpretable Network Rewiring Identifies Stress-Specific Regulatory Hub Genes in *Coptis teeta*

## Project overview

*Coptis teeta* is an endangered medicinal plant endemic to the Eastern Himalayas. It is an abundant natural source of the isoquinoline alkaloids berberine and coptisine.

Through this study, we look into gene co-expression patterns that differ between drought and heat stress in *C. teeta*.  First, we independently reprocessed the RNA-seq data published by Nath et al. (2026). Then, we created stress-specific co-expression networks and quantified changes in gene connectivity to find candidate genes associated with stress-responsive network reorganization.

The analysis uses biweight midcorrelation (bicor) which is outlier resistant, network centrality, multi-threshold robustness assessment, and an integrated candidate-prioritization framework.

The study is intended as a hypothesis-generating investigation. Network associations and functional annotations provide evidence for candidate genes. Their regulatory roles require experimental validation.

## Research objectives:

1. How do transcriptional responses differ between drought and heat stress?
2. Which genes exhibit the greatest changes in co-expression network connectivity between the two conditions?
3. Which candidate genes remain consistent across different correlation thresholds and scoring schemes?
4. Do independently reported annotations and sequence homology provide functional support for the prioritized candidates?

## Methodology

### 1. RNA-seq processing

We obtained raw RNA-seq reads from NCBI Sequence Read Archive (SRA) BioProject PRJNA1313294, originally generated by Nath et al. (2026).

We independently processed the reads using:
- `fasterq-dump` for FASTQ conversion
- HISAT2 for read alignment
- SAMtools for alignment processing
- featureCounts for gene-level quantification

We aligned the reads against the closely related *Coptis chinensis* reference genome (GCA_015680905.1) since a fully annotated *C. teeta* reference genome was unavailable.

### 2. Normalization and differential expression

We scaled the raw gene counts using the trimmed mean of M-values (TMM) method, implemented in edgeR, and transformed using logCPM.

Three comparisons were evaluated:
- Drought versus control
- Heat versus control
- Heat versus drought

We classified the genes according to their stress-response patterns. A total of 3,860 stress-responsive genes were retained for downstream analyses.

### 3. Co-expression network construction

We quantified the gene co-expression using biweight midcorrelation (bicor) with maxPOutliers = 0.10, implemented through the WGCNA package in R.

We created two drought-specific and heat-specific networks. We then defined the network edges using correlation thresholds, and quantified gene connectivity via degree centrality.

### 4. Network rewiring analysis

We assessed the stress-dependent network reorganization from the absolute difference in degree centrality between drought and heat networks:

`Degree_Difference = |Drought_Degree - Heat_Degree|`

We considered that genes with larger differences exhibit greater changes in network connectivity between the two stress conditions.

### 5. Robust hub identification

We evaluated the stability of the hub genes across four correlation thresholds: 0.6, 0.7, 0.8, and 0.9.

Genes that remained stable at three or more thresholds were classified as robust hubs.

### 6. Candidate prioritization

An integrated scoring framework combined five sources of evidence:

- Network importance
- Stress responsiveness
- Robustness across correlation thresholds
- Pathway evidence
- Gene Ontology evidence

We used alternative weighting schemes and evaluated the stability of the candidate rankings to complete the sensitivity analysis.

### 7. Functional annotation and statistical validation

We cross referenced the prioritized genes with the annotations from Nath et al. (2026) and benzylisoquinoline alkaloid biosynthetic gene sets curated from literature review.

We also explored the protein sequences of robust hub genes by running BLASTP against the NCBI non-redundant protein database, followed by annotation through the UniProt REST API.

We used Fisher's exact test to assess the enrichment of robust hubs among the most strongly rewired genes.

## Principal findings

The analysis identified:

- **3,860** stress-responsive genes.
- **24** robust hub genes consistently recovered across multiple correlation thresholds.
- **31** genes with pronounced network-rewiring signatures.
- **29** prioritized candidates comprising the 24 robust hubs and five additional high-ranking candidate genes.
- **20 of 24** robust hubs with functional identities assigned through homology-based annotation, of which 18 were considered sufficiently reliable for biological interpretation.

Two candidates received particular attention:

- **Tyrosine/DOPA decarboxylase (TYDC):** showed a substantial gain in network connectivity under drought compared with heat stress.
- **GATA family transcription factor:** was reported for drought-responsive expression in the published transcriptomic dataset.

These findings suggest that network rewiring can provide an interpretable approach to prioritizing candidate genes. This method can be especially valuable in non-model plant species with limited functional annotation and small sample sizes.

## Data availability

Raw RNA-seq data are publicly available through the NCBI Sequence Read Archive under BioProject **PRJNA1313294**.

The reference genome used for read alignment is *Coptis chinensis*, assembly **GCA_015680905.1**.

This repository contains the code and downstream analytical workflow developed for the study.

## Limitations

The analysis is subject to several limitations:

- The RNA-seq dataset contains only three biological replicates per condition. So, the statistical validity of co-expression network estimation is limited.
- The use of *C. chinensis* as a reference genome could affect the representation of species-specific transcripts.
- Co-expression relationships do not establish direct regulatory interactions or causality.
- The absence of paired metabolomic measurements prevents direct assessment of changes in berberine and coptisine accumulation.
- Functional assignments based on sequence homology require further experimental confirmation.

The prioritized genes should therefore be interpreted as candidates for future investigation.
